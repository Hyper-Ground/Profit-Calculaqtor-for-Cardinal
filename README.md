# Profit-Calculaqtor-for-Cardinal
Плагин позволяет быстро рассчитать примерную стоимость товара с учётом закупочной цены, наценки, комиссии FunPay и комиссии вывода. Поддерживает наценку в процентах и фиксированной суммой, разные валюты, автоматическое округление цены и сохранение рассчитанных товаров в список.
