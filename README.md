# 🔥 ProfitCalculator

### Плагин-калькулятор прибыли для FunPay Cardinal

ProfitCalculator — удобный плагин для Cardinal, который помогает быстро рассчитать итоговую стоимость товара с учётом закупочной цены, наценки, комиссии FunPay и комиссии вывода.

---

## 🚀 Возможности

* 🧮 Расчёт стоимости товара
* 📦 Сохранение товаров в список
* 📋 Просмотр сохранённых товаров
* ℹ️ Просмотр полной информации о товаре
* 🗑 Удаление товаров
* 💱 Поддержка нескольких валют (RUB, UAH, USD, EUR)
* ⚙️ Настройка комиссии FunPay
* 💳 Настройка комиссии вывода
* 🔄 Автоматическое округление цены под выбранную валюту

---

## 📌 Запуск

Для открытия плагина используйте команду:

```text
/calc
```

---

## 🧮 Расчёт стоимости

Для расчёта товара необходимо указать:

1. Название товара
2. Закупочную цену
3. Наценку

Наценка может быть указана двумя способами:

```text
20%   - процент от закупочной цены
100   - фиксированная сумма сверху
```

После расчёта плагин покажет итоговую стоимость товара и предложит добавить его в список.

---

## 📦 Управление товарами

### Список товаров

Позволяет просматривать все сохранённые товары.

Сначала отображается список товаров, после чего можно выбрать нужный товар кнопкой и открыть его полную информацию.

### Удаление товара

Для удаления товара:

```text
📦 Список товаров
      ↓
Выбрать товар
      ↓
🗑 Удалить этот товар
```

---

## ⚙️ Настройки

### 💱 Изменить валюту

Поддерживаемые валюты:

* RUB
* UAH
* USD
* EUR

### ⚙️ Изменить комиссию FunPay

Позволяет указать комиссию FunPay в процентах.

По умолчанию:

```text
9%
```

Рекомендуемое значение:

```text
20%
```

### 💳 Изменить комиссию вывода

Позволяет добавить комиссию вывода средств для более точного расчёта прибыли.

---

## 📥 Установка

1. Скачайте архив с плагином.
2. Распакуйте его в папку `plugins` вашего Cardinal.
3. Перезапустите Cardinal.
4. Откройте плагин командой:

```text
/calc
```
